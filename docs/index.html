Most common reasons for “File not found”

  1. Folder names must match EXACTLY (case-sensitive on GitHub Pages). Example: IcontrolFlow.html is not the same as IControlFlow.html.
  2. Spaces in folders must be URL-encoded. Example: Replaced Method must be linked as Replaced%20Method.
  3. You must put index.html inside the same /docs folder you selected in GitHub Pages settings.
