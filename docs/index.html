How to host from /docs

  1. Create a folder named docs in your repo.
  2. Put this file inside docs and name it index.html.
  3. Go to Settings → Pages.
  4. Set Source to Deploy from a branch.
  5. Select your branch (e.g., main) and folder /docs, then save.
