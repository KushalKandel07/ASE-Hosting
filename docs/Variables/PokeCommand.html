Class PokeCommand
BOOSE command implementation for writing a value into an array.
Syntax
C#
    public class PokeCommand : CanvasCommand, IAppCommand
Remarks
Syntax:
C#
poke array index = value
Examples:
C#
poke nums 5 = 99
poke prices 3 = 12.75
poke nums 1 = radius

The value can be:

  • An integer literal
  • A real (floating-point) literal
  • A variable (int or real)

Method Execute
Executes the array write operation at runtime.
Syntax
C#
    public override void Execute()
Remarks
The assignment logic attempts, in order:
  1. Integer literal assignment
  2. Real literal assignment
  3. Variable lookup (real first, then int)
This mirrors the behaviour of other BOOSE runtime commands.
