Class PeekCommand
BOOSE command implementation for reading a value from an array.
Syntax
C#
    public class PeekCommand : CanvasCommand, IAppCommand
Remarks
Syntax:
C#
peek target = array index
Example:
C#
peek x = nums 5

The command attempts to read from an integer array first; if that fails, it falls back to a real array. The target variable is declared or updated accordingly.
