Class RealDeclareCommand
BOOSE command implementation for declaring real (floating-point) variables.
Syntax
C#
    public class RealDeclareCommand : CanvasCommand, IAppCommand
Remarks
Supported syntax:
C#
real name
real name = expression
Examples:
C#
real length = 15.5
real pi = 3.14159
real circ = 2 * pi * radius

Expressions support +, -, *, /, numeric literals, and variables. Parentheses are not required for the expected coursework examples.

Method Execute
Executes the real declaration and optional initialization.
Syntax
C#
    public override void Execute()
Remarks
The declaration is redeclare-safe across GUI runs:
  • If the variable exists with a different type, it is removed.
  • If it does not exist, it is declared with a default value.
