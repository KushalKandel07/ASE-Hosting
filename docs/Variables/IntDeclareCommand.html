Class IntDeclareCommand
BOOSE command implementation for declaring integer variables.
Syntax
C#
    public class IntDeclareCommand : CanvasCommand, IAppCommand
Remarks
Supported syntax:
C#
int name
int name = value
Examples:
C#
int radius
int radius = 50
int radius=50

The command is redeclare-safe across GUI runs. If a variable with the same name exists but is not an integer, it is removed and re-declared.

Method Execute
Executes the integer declaration or update at runtime.
Syntax
C#
    public override void Execute()
Remarks
If the variable already exists:
  • If it is not an integer, it is removed.
  • If it is an integer, its value is updated.
This behaviour supports repeated executions from the GUI without stale state.
