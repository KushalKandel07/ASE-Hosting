Method Execute
Executes the array declaration at runtime.
Syntax
C#
    public override void Execute()
Remarks
If an array with the same name already exists:
  • If the type differs, the old variable is removed and re-declared.
  • If the type matches, execution is skipped.
This allows safe re-runs from the GUI without interpreter state conflicts.
