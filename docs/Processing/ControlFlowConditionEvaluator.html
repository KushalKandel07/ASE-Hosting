Class ControlFlowConditionEvaluator
Evaluates conditional expressions used by replaced control-flow commands such as if, while, and for. Supported comparison operators:
  • <
  • >
  • <=
  • >=
  • ==
  • !=
Numeric resolution order:

1) literal → 2) real variable → 3) int variable

Syntax
C#
    internal static class ControlFlowConditionEvaluator

Method Eval

C#

Parameters
condition
Condition string (e.g. height > 50, x == y).
Return Value
true if the condition evaluates to true; otherwise false.
Exceptions

Method Resolve
Resolves a numeric token into a double.
Syntax
C#
    public static double Resolve(string token)
Parameters
token
Numeric literal or runtime variable name.
Return Value
The resolved numeric value.
Remarks
Resolution order is:

literal → real variable → int variable

This mirrors the behavior used throughout the replaced BOOSE runtime.
