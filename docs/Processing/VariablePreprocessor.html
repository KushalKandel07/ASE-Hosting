Documentation Preview
Property class
Preprocesses BOOSE source code to support replaced variables/features:
  • int, real, boolean declarations (including boolean AND: &&)
  • array declarations for int/real arrays
  • poke and peek for array set/get
  • Simple assignments and arithmetic expressions where enabled
  • Resolution of runtime numeric expressions inside drawing commands
This class executes variable-related statements immediately (updating Variables) and removes those lines from the BOOSE code so the restricted interpreter does not see them.
Syntax
C#
    public sealed class VariablePreprocessor
