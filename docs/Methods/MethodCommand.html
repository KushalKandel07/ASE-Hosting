Property class
Implements the BOOSE replaced method facility.

Example:

C#
method int mulMethod int one, int two
  mulMethod = one * two
end method

This command does not execute as a single line; instead, it is handled as a multi-line control-flow block by ExecuteControlFlow(ControlFlowExecutor, List{string}, ref int).

Syntax
C#
    public sealed class MethodCommand : CanvasCommand, IAppCommand, IControlFlowCommand

Method ExecuteControlFlow
Parses a method ... end method block and registers the resulting method definition.
Syntax
C#
    public void ExecuteControlFlow(ControlFlowExecutor executor, List<string> lines, ref int i)
Parameters
executor
Control flow executor invoking this command.
lines
All program lines.
i
Current line index. On entry points to the method ... line. On exit points to the first line after end method.
Exceptions
Exception Condition
BOOSEException Thrown when the method block is malformed or missing a return assignment.
