Property class
Facade responsible for executing BOOSE programs end-to-end.
Syntax
C#
    public sealed class BooseInterpreterFacade : IBooseInterpreterFacade
Remarks
This class encapsulates the full interpreter workflow so that the UI layer interacts with a single, clean entry point. Responsibilities include:
  • Canvas creation and reset
  • Runtime state reset (variables and methods)
  • Command factory setup
  • Unrestricted execution (control-flow supported)
This design follows the Facade pattern, improving separation of concerns and testability.
