Represents the result of executing a BOOSE program.
Syntax
C#
    public sealed class BooseRunResult
Remarks
This value object encapsulates the final rendered bitmap produced by the canvas and any optional textual output captured during execution. It is intentionally immutable to ensure result integrity after execution.
