Interface IBooseInterpreterFacade
Defines the public facade for executing BOOSE programs.
Syntax
C#
    public interface IBooseInterpreterFacade
Remarks
The UI layer should depend only on this interface and not on concrete interpreter, executor, or runtime classes. This abstraction:
  • Improves separation of concerns
  • Supports unit testing via mocking or stubbing
  • Enforces a clean execution contract
