Method button1_Click
Executes the BOOSE program entered in the program text box.
Syntax
C#
    private void button1_Click(object sender, EventArgs e)
Parameters
sender
The event sender (Run button).
e
Event arguments.
Remarks
Execution flow:
  1. Validates input.
  2. Creates a fresh canvas state (clear + reset) to match expected example outputs.
  3. Runs the unrestricted executor (supports if/while/for and replaced facilities).
  4. Displays the resulting bitmap in the PictureBox.

A temporary canvas/program is used so that if execution fails, the previous successful output remains visible to the user.
