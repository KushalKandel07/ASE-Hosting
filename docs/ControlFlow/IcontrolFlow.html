Interface IControlFlowCommand
Defines the contract for multi-line BOOSE control-flow commands.
Syntax
C#
    public interface IControlFlowCommand
Remarks
This interface is implemented by replaced/unrestricted control-flow commands such as:
  • if
  • while
  • for
These commands cannot be executed using the standard single-line Execute() method. Instead, they require access to:
  • The full list of program lines
  • The current execution index
  • The unrestricted ControlFlowExecutor
so that nested blocks and loop bodies can be processed correctly.

Method ExecuteControlFlow
Executes a multi-line control-flow block.
Syntax
C#
    void ExecuteControlFlow(ControlFlowExecutor executor, List<string> lines, ref int i)
Parameters
executor
The ControlFlowExecutor responsible for executing nested blocks and dispatching commands.
lines
All lines of the BOOSE program currently being executed.
i
Reference to the current line index. Implementations must advance this index so that execution resumes immediately after the corresponding end statement (e.g., end if, end while, end for).
