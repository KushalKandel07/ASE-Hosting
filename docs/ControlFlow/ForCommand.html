Property class
Replaced for command (unrestricted).
Syntax
C#
    public sealed class ForCommand : CanvasCommand, IAppCommand, IControlFlowCommand
Remarks
Supported syntax (typical BOOSE):
  • for i = 1 to 10
  • for i = 1 to 10 step 2
  • end for
This is a multi-line construct; execution is delegated to ControlFlowExecutor via ExecuteControlFlow.
