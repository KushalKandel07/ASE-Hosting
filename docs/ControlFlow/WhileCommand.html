Property class
Replaced BOOSE while command (unrestricted).
Syntax
C#
    public sealed class WhileCommand : CanvasCommand, IAppCommand, IControlFlowCommand
Remarks
Supported syntax:
C#
while <condition>
  ...
end while

This is a multi-line control-flow command. The standard Execute method is intentionally unused; execution is delegated to ExecuteControlFlow.

Method ExecuteControlFlow
Executes the full while loop using the unrestricted control-flow executor.
Syntax
C#
    public void ExecuteControlFlow(ControlFlowExecutor executor, List<string> lines, ref int i)
Parameters
executor
Executor responsible for evaluating and running the loop body.
lines
All program lines.
i
Current line index. On entry, points at the while line. On exit, points just after the matching end while.
Exceptions
Exception Condition
BOOSEException Thrown when end while is missing.
