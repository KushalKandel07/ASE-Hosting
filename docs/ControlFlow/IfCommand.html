Property class
Replaced BOOSE if command (unrestricted).
Syntax
C#
    public sealed class IfCommand : CanvasCommand, IAppCommand, IControlFlowCommand
Remarks
Supported syntax:
C#
if <condition>
  ...
else
  ...
end if

This is a multi-line control-flow construct. The normal Execute method is not used; execution is handled through ExecuteControlFlow.

Method ExecuteControlFlow
Executes the full if block (including optional else) using the control-flow executor.
Syntax
C#
    public void ExecuteControlFlow(ControlFlowExecutor executor, List<string> lines, ref int i)
Parameters
executor
Executor responsible for running sub-blocks.
lines
All program lines.
i
Current line index. On entry it points at the if header line. On exit it points just after the matching end if.
Exceptions
Exception Condition
BOOSEException Thrown when end if is missing.
